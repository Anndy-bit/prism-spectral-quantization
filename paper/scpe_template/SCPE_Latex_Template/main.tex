\section{Formatting Guidelines}

\subsection{Equations}
Please use the standard LaTeX \texttt{equation} environment. \textbf{DO NOT} use external packages like \texttt{\textbackslash scalebox} or \texttt{\textbackslash resizebox} to shrink equations. If an equation is too long, break it using \texttt{split} or \texttt{align}.
\begin{equation}
    E = mc^2
\end{equation}

\subsection{Figures and Tables}
All figures must be provided in high resolution (at least 300 DPI) using PDF, PNG, or JPEG formats. Do not insert formulas as images.
